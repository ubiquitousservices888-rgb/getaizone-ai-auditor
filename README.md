# GetAIZone AI Spend & Risk Auditor

GetAIZone is a standalone, dependency-light micro-SaaS MVP for auditing AI/software spend, security risk, automation opportunity, and governance readiness.

## Current verified capabilities

- Free browser-based audit with no login required
- Deterministic scoring across four categories
- Rule-based findings with explanations and prioritized actions
- Estimated savings ranges derived only from user-entered monthly spend and disclosed assumptions
- Mobile-first results dashboard
- Privacy warning: users are explicitly told not to enter secrets, passwords, or API keys
- No external AI API required
- No database required for the MVP
- No payment system is represented as live

## Product intent

The MVP is designed for rapid launch on GetAIZone.com, lead generation, future paid reporting/optimization services, and clean buyer handoff as a standalone micro-SaaS asset.

## Deployment

Static frontend. Suitable for direct deployment to Vercel with no build step.
